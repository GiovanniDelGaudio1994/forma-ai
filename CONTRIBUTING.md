# Contribuire a FORMA AI

FORMA AI è un prototipo educativo e open source orientato a una Home Gym.

## Ambiente di sviluppo

Richiede Node.js 22+. Non sono necessarie dipendenze esterne per eseguire l'app principale.

```bash
npm test
npm run check
npm start
```

Apri la PWA su `http://127.0.0.1:8787`.

## Contributi

- Apri un'issue descrivendo il problema e la soluzione proposta.
- Mantieni le modifiche piccole, leggibili e accompagnate da test.
- Non includere dati sanitari, immagini personali, `.env`, chiavi API o backup.
- Mantieni dichiarati i limiti dei moduli AI e Video Lab.
- Le funzionalità legate ad allergie, celiachia e piani alimentari richiedono test e una revisione professionale prima di un uso pubblico generalizzato.

## Filosofia di sviluppo

Privacy by default, minimizzazione dei dati, graceful degradation offline e niente promesse mediche non verificate.
