# Fit Zone — anteprima frontend fedele al sito originale

Questa anteprima deriva dalle pagine PHP, dai fogli CSS, dalle immagini e dallo script JavaScript forniti nel progetto **Fit Zone**.

- **Interfaccia**: HTML prodotto dai template originali PHP senza modificarne layout, testi statici o classi CSS. Gli stili e le fotografie sono originali dello ZIP (convertiti in WebP solo per alleggerire la pagina).
- **Dati**: sono presenti dati dimostrativi non personali dove il sito originale interrogava MySQL. Non vengono esposti dati degli utenti, delle testimonianze originali o contatti reali.
- **Limiti**: GitHub Pages non esegue PHP e MySQL; quindi login, registrazione, messaggi, acquisti e prenotazioni non scrivono dati e mostrano un avviso esplicito. Le sessioni demo non sono reali.
- **Backend**: la versione PHP ripulita è disponibile nella cartella `projects/fit-zone/source/` della repository pubblica del portfolio.
- **Licenze immagini**: le fotografie provengono dai file forniti dall'autore; occorre verificarne licenze/attribuzioni prima di qualunque distribuzione commerciale.

La precedente demo scura è stata rimossa perché non rispecchiava il progetto consegnato.
